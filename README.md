# Marginalia 📚

A minimalist CLI ebook reader for Linux.

### Features
- Supports .epub, .pdf, and raw text.
- Split-screen: Read on the left, type Markdown notes on the right.
- Auto-saves progress.

### Install
1. Clone this repo.
2. Set up a virtual environment and install dependencies: 'pip install textual pypdf ebooklib beautifulsoup4 rich'
3. Run 'python marginalia.py <file_path>'
